# Отрядный конструктор

Программа для распределения детей по отрядам и комнатам лагеря.

- Загружает списки детей из Excel (.xlsx, .xls, в том числе выгрузки с сайта), можно несколько файлов и листов сразу. Повторы по ФИО и дате рождения пропускаются.
- Отряды и комнаты задаются вручную или шаблоном. Число мест в комнате, новые комнаты и свободные места меняются прямо на доске распределения.
- Пожелания родителей: «одна комната», «один отряд», «разные отряды». Программа сама находит в комментариях фамилии и имена других детей и предлагает пары.
- Автораспределение: дети идут по возрасту, группы по пожеланиям держатся вместе, комнаты получаются только для мальчиков или только для девочек, родные братья или сестры одного пола по возможности селятся вместе.
- Столовая: три зала (Основной — 30 столов, Кемптон — 28, Веранда — 16) по 6 мест, автоматическая рассадка отрядов, закрепление столов, перетаскивание детей, выгрузка рассадки в Excel.
- Ручная правка перетаскиванием. Переставленный вручную ребёнок закрепляется и при повторном автораспределении остаётся на месте.
- Выгрузка в Excel: сводка и отдельный лист на каждый отряд (№, ФИО, дата рождения, родитель, телефон, адрес, район, комментарии, категория, комната).
- Проект целиком сохраняется в файл .json и открывается позже.

Данные детей обрабатываются только на вашем компьютере и никуда не отправляются.

## Скачать

Готовые файлы лежат в разделе **Releases** этого репозитория.

### Windows

- `Otryad-Constructor-Setup-*.exe` — установщик на русском языке: выбор папки, ярлыки на Рабочем столе и в меню «Пуск», удаление через «Параметры → Приложения»;
- `Otryad-Constructor-*-portable.exe` — версия без установки, запускается сразу.

У программы нет платной цифровой подписи. Windows может показать «Система Windows защитила ваш компьютер»: нажмите «Подробнее» → «Выполнить в любом случае». Если включено «Интеллектуальное управление приложениями» (Smart App Control), установщик может быть заблокирован совсем; тогда используйте portable-версию.

### macOS (Intel и Apple Silicon)

- `Otryad-Constructor-*-mac.dmg` — откройте и перетащите «Отрядный конструктор» в папку «Программы» (внутри файл приложения называется `Otryad Constructor.app`: русское имя файла приложения на macOS 26 приводит к падению Electron при запуске);
- `Otryad-Constructor-*-mac.zip` — то же приложение в архиве.

Приложение не заверено Apple (для этого нужна платная учётная запись разработчика), поэтому при первом запуске macOS его не откроет. Сделайте один раз:

1. Попробуйте открыть программу из «Программ» и закройте предупреждение.
2. Откройте «Системные настройки» → «Конфиденциальность и безопасность», прокрутите вниз и нажмите «Всё равно открыть» рядом с «Отрядный конструктор».
3. Подтвердите паролем от Mac.

Если macOS пишет, что приложение «повреждено», выполните в Терминале команду `xattr -cr "/Applications/Otryad Constructor.app"` и откройте программу снова.

## Сборка из исходников

Нужен Node.js 22 или новее.

```bash
npm install
npm start
```

Собрать exe (на Windows) или dmg (на Mac):

```bash
npm run dist
```

```bash
npm run dist:mac
```

Файлы появятся в папке `dist`. При каждом коммите в `main` и при новом теге `v*` версии для Windows и Mac собираются автоматически в GitHub Actions, для тегов они сразу выкладываются в Releases.

## Устройство

- `app/index.html` — весь интерфейс и логика распределения (обычная веб-страница, работает и в браузере).
- `main.js` — окно приложения и системный диалог «Сохранить как».
- `preload.js` — мост между страницей и окном.
